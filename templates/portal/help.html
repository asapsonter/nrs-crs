Primary and Secondary Users

The Primary User is created when the institution's enrolment is approved, and administers the institution's access, creating Secondary Users under Manage Users. Both the Primary User and Secondary Users prepare and submit CRS filings to the NRS directly.

Preparing a return

  1. Open Submissions and choose CRS XML upload, manual entry, or a nil return.
  2. For an XML upload, the Portal validates the file against the CRS schema on upload.
  3. When every form shows Validated, select Validate & Submit to transmit the filing to the NRS.
  4. If the NRS returns a filing for correction, it appears under Draft Filings for you to amend and resubmit.

Need assistance

For enrolment changes or questions the Portal cannot answer, contact the NRS AEOI-CRS unit. Keep your Reporting Entity reference to hand.
